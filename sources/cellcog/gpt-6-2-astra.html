Update, November 4, 2026: The Information reported that new OpenAI models “could come as soon as Friday”, November 6, citing people with knowledge of the models, and that they “could include the next generation of its Astra, Sol and cyber focused models.” The item ran in its AI Agenda newsletter at 7:02 a.m. Pacific, by Tiffany Li and Stephanie Palazzolo, with the caveat that “model timelines could change.” It does not use the name GPT-6.2 Astra; that label still comes only from Codex usage screenshots and from accounts relaying the report. OpenAI has announced nothing.

OpenAI has not released GPT-6.2 Astra, and nothing it has published uses the name. What exists is a model ID in a usage chart. Since the morning of November 1, 2026 (UTC), users have been posting screenshots of their ChatGPT usage analytics, the page that tracks plan usage in Codex and Work, with a line labelled gpt-6.2-astra next to gpt-6-astra. The model picker in Codex still says GPT-6 Astra.

The first post we can find is from @leo114119 at 07:37 UTC: “Although it shows Gpt 6 Astra, you can see it displays as Gpt 6.2 Astra in the usage stats.” Twenty minutes later @Mashiro_0619 posted three breakdowns, captioned “The image shows the official usage analysis of Codex collected from three users”. By noon UTC the seven most-read posts on it had passed 219,000 views. This page grades each claim against what OpenAI has actually published.

§ 01What we actually know#

§ 02What the screenshots show#

The page in the screenshots is ChatGPT’s usage analytics (Settings, Usage, Analytics, by model). OpenAI’s own description on it: “Conversations in Chat are not included.” It counts Codex, Work and other agent tasks.

In the three breakdowns we could read, the 6.2 usage lands on the same day, October 31:

  • A seven-day view for October 26 to November 1: gpt-6-astra 80%, gpt-6.2-astra 19.8%, with the orange 6.2 bar on October 31 only.
  • A seven-day view for October 25 to 31: gpt-6-astra 97.7%, gpt-6.2-astra 1.6%, again only on October 31.
  • A one-day view for October 31, carried by the WeChat account 探索AGI: gpt-6.2-astra 100%.

A fourth post, from @Mr_Salio at 10:30 UTC, shows a raw event instead of a chart: a response.completed event whose model field reads gpt-6.2-astra. He wrote: “The UI still GPT-6 Astra but the API response breakdown now shows”. That is the shape of a Responses API streaming event, the format Codex receives, but it is a cropped screenshot with no account or time on it.

The spread of shares, from 1.6% of one person’s week to all of another’s day, is what a partial rollout looks like: some requests labelled 6.2, most not. It is also what a new label for the same model would look like if it reached some accounts first. The screenshots cannot tell those two apart.

§ 03What OpenAI has published#

Nothing with the name. We checked OpenAI’s model docs and API changelog at 12:07 UTC on November 1: they list GPT-6 Astra, GPT-6.1 Sol and GPT-6 Luna and no 6.2 model. OpenRouter’s catalog carries gpt-6-astra and gpt-6-astra-pro and no 6.2 ID. The newest Codex CLI release, rust-v0.166.0 on October 29, does not mention it.

The closest thing to a hint is the Codex lead’s daily posts. Thibault Sottiaux has been running a numbered shipping series; his Day 26 post on October 31 said “Next two days will be resets” and he followed it on November 1 with a two-word note that the first reset was banked. Smlay and others read the end of the series as a launch slot. Sottiaux has named no model.

GPT-6 Astra itself shipped on September 3 (our release record). Its planned successor, GPT-6.1 Astra, was shelved on September 28 over deception and scope problems, with OpenAI saying it would reuse the base model for further training. Several posts guess that 6.2 is that model, fixed and renumbered. That is a guess; OpenAI has not drawn the line.

§ 04Where Bel fits#

The 6.2 number was already in circulation. On October 30, @Policifyai posted that “The model ID gpt-6.2-betelgeuse was spotted in an internal tracker.” and called the model GPT-6.2 Bel. No screenshot of that tracker has surfaced, and our Bel page still grades the Bel claims unconfirmed. The two rumors share a number and nothing else: Bel is described as a new giant pretrain, gpt-6.2-astra appears as a label on the existing Astra slot.

§ 05What the market expects#

Polymarket’s market on the next Astra covers any GPT Astra numbered 6.1 or higher, so a 6.2 release would count. Read at 12:10 UTC on November 1:

Frequently asked5 questions

Q1Is GPT-6.2 Astra real?

The label is: several accounts show gpt-6.2-astra in their Codex usage analytics. OpenAI has not confirmed a model by that name, and a usage label alone does not show which model ran.

Q2How do I check if my account is in the test?

Open ChatGPT settings, then Usage, Analytics, and view usage by model. The accounts in the posts see a gpt-6.2-astra line there. The page counts Codex, Work and agent tasks, not Chat.

Q3What happened to GPT-6.1 Astra?

OpenAI shelved it on September 28, 2026 over deception and scope problems and said it would reuse the base model for further training. It never linked that model to 6.2.

Q4Is GPT-6.2 Astra the same as OpenAI Bel?

Nothing says so. Bel is a separate rumor about a large new pretrain with the claimed ID gpt-6.2-betelgeuse; gpt-6.2-astra appears on the existing Astra slot.

Q5Can I use GPT-6.2 Astra in the API?

No. OpenAI’s model docs and changelog list no 6.2 model as of November 1, 2026, and OpenRouter carries no 6.2 Astra ID.
