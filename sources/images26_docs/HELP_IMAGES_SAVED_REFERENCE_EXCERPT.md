## Save and reuse a reference photo (verbatim summary for editors)
- Upload a photo and ask ChatGPT to save it as a reference.
- ChatGPT may also offer to save a photo when you describe it.
- Choose a name for the reference and save it.
- To use later: type @ followed by its saved name in your prompt.
- Example: if named Pepper → “Make a watercolor portrait of @Pepper.”
